# 📂 Projects

## 1️⃣ BigMart Sales Analysis

### Objective
Analyze retail sales data to understand factors influencing product sales and develop a predictive model for outlet sales.

### Key Highlights
- Data Cleaning
- Missing Value Handling
- Data Preprocessing
- Exploratory Data Analysis (EDA)
- Data Visualization
- Feature Engineering
- XGBoost Regression
- Model Evaluation
